LANGKAH DI VPS
═══════════════════════════════════════════════════════════════════

Step 1: Copy semua file di atas ke VPS (sesuai path masing-masing)

Step 2: Build frontend di VPS:
   cd C:\inetpub\wwwroot\portofolio-faturachman
   npm run build

Step 3: Copy dist ke webroot IIS:
   Copy-Item -Path ".\dist\*" -Destination "C:\inetpub\wwwroot" -Recurse -Force

Step 4: Restart backend:
   cd server
   pm2 restart ting-ai-backend --update-env
   pm2 save

Step 5: Hard refresh browser (Ctrl+Shift+R) untuk clear cache
