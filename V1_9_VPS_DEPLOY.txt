## LANGKAH DI VPS

### Step 1: Copy semua file di atas ke VPS
```
Sesuai path masing-masing ke:
C:\inetpub\wwwroot\portofolio-faturachman\
```

### Step 2: Build frontend
```powershell
cd C:\inetpub\wwwroot\portofolio-faturachman
npm run build
Copy-Item -Path ".\dist\*" -Destination "C:\inetpub\wwwroot" -Recurse -Force
```

### Step 3: Clear browser cache
```
Ctrl + Shift + R di browser
```
